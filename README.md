# FlyRank Capstone — Embeddable Widget & Lead-Capture Platform

Customers define a widget, get a one-line `<script>` embed, and the backend safely
handles public submissions: validated, rate-limited, spam-filtered, geo-enriched,
stored, and exposed via an owner dashboard API.

> Status: in progress — Phase 1 (design).

## Stack
Python 3.12 · FastAPI · PostgreSQL (Docker) · SQLAlchemy + Alembic · Pydantic
