How the widget got here

This page is served from . The API lives on http://localhost:8000, a different origin. The only integration is the one-line snippet (plus an optional placement div):

<script src="http://localhost:8000/widget.js?id=wgt_demo000001" async></script>

The dark popover in the corner is a second widget (wgt_demopopup1) added with the same kind of snippet.
